# COOP Report — سجل التدريب التعاوني الذكي المتكامل (Huawei Co-op)

تطبيق ويب متكامل عالي الاحترافية صُمم خصيصاً لمتدربي التدريب التعاوني (Co-op) في شركة هواوي السعودية ولأي جهة أكاديمية أو مهنية.

---

## أبرز المزايا والمواصفات المطبقة

1. **الالتزام الكامل بعدم استخدام الإيموجيز (Zero Emojis):**
   - اعتماد كامل على أيقونات SVG دقيقة وعصرية عبر مكتبة `lucide-react` في كافة مكونات النظام دون أي رموز تعبيرية.

2. **قاعدة بيانات MySQL حقيقية عبر Prisma ORM:**
   - مخطط MySQL منظم ومطابق للمواصفات الأكاديمية والمهنية (`users`, `entries`, `report_profile`).
   - تشفير كلمات المرور باستخدام `bcrypt` (12 جولة تشفير).
   - عزل تام للبيانات بمستوى الـ Database والـ Middleware عبر `user_id`.

3. **محرك الذكاء الاصطناعي اللغوي والترجمة الذاتية الفورية:**
   - **ترجمة ذاتية فورية (عربي <-> إنجليزي):** إمكانية ترجمة التقرير بالكامل (الغلاف، المقدمة، الإنجازات، المهارات، الخاتمة) دون أي تدخل يدوي.
   - **تنقيح وصياغة أكاديمية:** رفع مستوى التقرير إلى الأسلوب الأكاديمي والمهني الرصين.
   - **تصحيح إملائي ونحوي دقيق:** فحص الهمزات، علامات الترقيم، والتاء المربوطة.
   - **اختصار وإيجاز علمي:** تلخيص الإنجازات مع الحفاظ على الأرقام والمكتسبات الجوهرية.
   - **نافذة مقارنة مرئية (Diff View):** استعراض الفروقات قبل اعتماد أي تعديل.
   - يعمل عبر حزمة `@anthropic-ai/sdk` الرسمية مع توفر محرك لغوي أكاديمي داخلي ذكي كخيار احتياطي لضمان عدم توقف النظام أبداً.

4. **نظام الفهرسة التفاعلي والتصدير الثلاثي (DOCX, PDF, HTML):**
   - **فهرس تفاعلي ذكي (Table of Contents):** روابط تنقل سلسة لكافة الأقسام والأسابيع.
   - **تصدير Word (.docx) حقيقي:** عبر مكتبة `docx` بالمواصفات الأكاديمية (هوامش 2.5سم، خطوط وجداول منسقة، أرقام صفحات ورؤوس وتذييلات).
   - **تصدير تقرير HTML مستقل:** ملف HTML مستقل تماماً يعمل أوفلاين مع إمكانية الطباعة.
   - **طباعة وحفظ PDF:** تنسيق `@media print` متقدم يخفي الواجهات والأزرار لعزل التقرير الرسمي.
   - **عداد صفحات تقديري حي:** حساب عدد الكلمات ÷ 350 مع شارة تنبيه لتحقيق شرط الـ 20 صفحة.

5. **بوابة المشرف التدريبي ونظام الربط:**
   - دعم كامل لدور المشرف (`supervisor`) والمتدرب (`trainee`).
   - إمكانية ربط المتدرب بمشرفه عبر اسم المستخدم.
   - لوحة تحكم للمشرف لاستعراض المتدربين، سجلاتهم اليومية، ساعاتهم المنجزة، مراجعة التقرير النهائي، وإضافة الملاحظات التقييمية.

## التشغيل السريع (Quick Start)

### 1. إعداد قاعدة بيانات MySQL:
تأكد من تشغيل خادم MySQL (مثل XAMPP أو خدمة MySQL على المنفذ 3306)، ثم أنشئ قاعدة البيانات:
```sql
CREATE DATABASE coop_report CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 2. تثبيت الحزم وتشغيل النظام:
```bash
# تثبيت التبعيات
npm install

# توليد مخطط Prisma ومزامنة قاعدة البيانات
npm run prisma:generate --workspace=server
npm run prisma:push --workspace=server

# تشغيل خادم التطوير (الواجهة والسيرفر معاً)
npm run dev
```

- رابط الواجهة: `http://localhost:5173`
- رابط السيرفر والـ API: `http://localhost:5000`

### 3. تشغيل الاختبارات الآلية (Vitest):
```bash
npm test
```
